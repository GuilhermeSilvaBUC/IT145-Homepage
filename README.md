# IT145 - Personal Portfolio Website

## Project Description

This project is a personal portfolio website created for IT145: Introduction to Programming. The purpose of this website is to introduce myself, demonstrate my programming skills, and showcase projects I have completed during the course.

## Website Pages

The website includes four pages:

1. Home (index.html) - Introduction and overview of my programming experience.
2. About (about.html) - Information about my background, education, and goals.
3. Projects (projects.html) - Examples of programming assignments completed during IT145.
4. Contact (contact.html) - An interactive demonstration contact form.

## Technologies Used

- HTML5 - Website structure and content.
- CSS3 - Website design, colors, and responsive layout.
- JavaScript - Dark mode functionality and contact form interaction.
- GitHub Pages - Website hosting.

## Website Features

- Four connected HTML pages.
- Responsive design for computers and mobile devices.
- Dark mode button with saved preferences.
- Interactive contact form with input validation.
- Project cards displaying programming assignments.
- Navigation menu connecting all pages.

## Programming Projects

The website showcases several projects completed during IT145:

1. Mario Pyramid - A C program that generates a pyramid using loops.
2. Cash Calculator - A C program that calculates the minimum number of coins needed for change.
3. Scrabble - A C program that compares word scores.
4. Songs Database - An SQL project for searching and analyzing music data.
5. Maximum Depth of Binary Tree - A Python solution using recursion.
6. Same Tree - A Python program that compares two binary trees.

## How to Run the Website

1. Download the project files from GitHub.
2. Open the homepage folder.
3. Open index.html in a web browser.
4. Use the navigation menu to explore the website.

## JavaScript Functionality

The website includes two JavaScript features.

The first feature is a dark mode button that allows users to switch between light and dark themes. The selected theme is saved using localStorage.

The second feature is a contact form that checks whether the user has completed the required fields and displays a confirmation message. This is a demonstration form and does not send actual emails.

## Project Purpose

This assignment helped me practice creating a complete website using HTML, CSS, and JavaScript. I learned how to organize multiple pages, apply consistent styling, create interactive features, and prepare a project for publication on GitHub.
